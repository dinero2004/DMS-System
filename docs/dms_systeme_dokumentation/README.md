# Dokumentationspaket: Drei DMS-Systeme

Stand: 05.08.2026  
Projektkontext: Creative Studio 3 / DMS-Systeme für Autohäuser

Dieses Verzeichnis enthält ein Hauptdokument und drei Einzeldokumentationen zu den DMS-Systemen im Workspace `DMS_System_DEMO/dealer-management-systems`.

## Dokumente

1. `00_Hauptdokument_Technische_Grundsaetze_und_Struktur.md`  
   Gemeinsame technische Grundsätze, Architektur, Docker-Verwaltung, GitHub-Ablage, Technologieentscheidungen und Quellen.

2. `01_ValuPilot_DMS_Dokumentation.md`  
   Dokumentation des Bewertungs-MVPs mit Spring Boot, React, PostgreSQL und erklärbarer Bewertungslogik.

3. `02_DealerOps_Command_DMS_Dokumentation.md`  
   Dokumentation der umfangreicheren Operations-Suite mit Kunden, Fahrzeugen, Werkstatt, Verkauf, Finanzierung, Finanzen, PDF-Ausgabe und Authentifizierung.

4. `03_Veloce_Dealer_OS_Dokumentation.md`  
   Dokumentation des leichten Node.js-Dashboards auf Basis einer exportierten JSON-Datenbasis.

## Zielgruppe

Die Dokumente richten sich an Webentwicklungs-Diplomstudierende, die verstehen möchten, wie ein Dealer-Management-System schrittweise konzipiert, strukturiert, containerisiert und visuell gestaltet werden kann.

## GitHub-Ablage

Der Code wurde in das GitHub-Repository `https://github.com/dinero2004/DMS-System.git` hochgeladen. Die drei Systeme liegen darin als Teil des gemeinsamen DMS-Workspaces.
